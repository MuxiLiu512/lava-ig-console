# Lava Reels 視覺方向研究

## 0. 先講結論：Jesse 的判斷是對的，而且比他說的更嚴重

三個查得到的數字，直接否定「九張轉檔」這條路：

| 數據 | 值 | 來源 |
|---|---|---|
| Reels 完播率（<15 秒） | 66.9% | highviz.io 2026 報告，315 支 Reels／96 帳號，逐格分析，2026-07-20 更新 |
| 完播率（15-30 秒） | 31.6% | 同上 |
| 完播率（30-60 秒） | 20.3% | 同上 |
| 開場型態互動率：B-roll／電影感 | 9.1% | 同上 |
| 開場型態互動率：純字卡宣傳 | 5.3% | 同上 |
| 開場型態互動率：無語音純配樂 | 3.3% | 同上 |
| 有字幕疊字：互動 7.7%／完播 37.4% | 對比無疊字 5.6%／46.8% | 同上 |

[驗證] https://www.highviz.io/instagram-reels-report

**三個「所以呢」：**

1. **九張講完至少 25-30 秒，直接掉進 31.6% 的區間。** 現有輪播結構（Hook→共感→知識×3→置入→應用→立場→CTA）在 Reels 是物理上做不到的。Reels 版本必須是「一篇貼文抽一個點」，不是「九張全講完」。輪播繼續做九張，Reels 是它的預告片，不是它的錄影。

2. **純字卡開場的互動率只有電影感開場的 58%。** 這一條打臉整個「kinetic typography 就是解法」的市場論述。把投影片加上打字動畫，仍然是純字卡開場，效果不會變。Jesse 的批評抓到的正是這個。

3. **無語音純配樂是所有開場型態裡最差的（3.3%）。** highviz 統計出的最常見弱點就是「缺少口說內容」。Lava 現在的轉檔版正是無語音。Seedance 2.0 可生成原生音訊，這是必須用上的能力，不是加分項。

## 2. 知識型 Reels 怎麼解「資訊密度 vs 視覺刺激」

這對矛盾的正解不是「壓縮資訊」，是**把資訊拆到多支影片，讓單支只承載一個轉折**。

**@visualizevalue（482K，1,059 篇）**
Jack Butcher 的方法論公開命名為 **TRAIN**：Typography、Restraint、Alignment、Image treatment、Negative Space。核心是「約束先於創意」，先鎖死一組視覺約束，再讓內容在裡面跑。
[驗證] https://growthinreverse.com/jack-butcher/

對 Lava 的意義：Reels 的一致性不能靠「每支都精心設計」，要靠**一組寫死的視覺約束**。這是一人團隊每週三篇唯一可能的路。

**@報導者 twreporter（301K）**
台灣深度媒體，用資訊圖與帶疊字的靜態影像處理硬題材。他們的作法是把一篇長報導拆出**一個數字或一句判斷**當作單則社群素材，不試圖轉述全文。

**@womany 女人迷（221K）**
極簡字卡、置中排版、統一浮水印。追蹤 221K 但形態偏靜態，說明**在台灣，靜態字卡到 20 萬量級是天花板附近**。Lava 要突破 200 追蹤的觸及天花板，不能複製這條路。

**@海苔熊（76.3K）**
台灣關係心理學的內容力上限參照。76.3K 說明台灣「感情心理知識」這個題材的天然池子有多大。[推理] Lava 若只做同題材，天花板大約在這個量級，差異化必須來自「offline 主張」而非「心理知識」本身。

## 3. 無真人出鏡的成功案例與拆解

**最重要的一句：無真人出鏡 ≠ 無人。**

Lava 的限制是「沒有代言人、Jesse 不出鏡、沒有實拍」，不是「畫面不能有人」。Seedance 2.0 可以生成人，只是不能是真實的、可辨識的、需要授權的人。這打開了整片可執行空間：

| 手法 | 出處 | Seedance 可行性 |
|---|---|---|
| **POV 第一人稱** | 通用 faceless 格式，鏡頭是「你看到的」不是「你是誰」 | 高。prompt 直接指定 POV 視角 |
| **手部特寫** | faceless UGC 主流格式 | 高。手拿手機、放下手機、推杯子 |
| **背影／剪影／過肩** | 電影語言 | 高，且 identity 一致性不成問題 |
| **角色化非人代理** | @thesecurerelationship 的鳥 | 高。Seedance image_references 可鎖角色 |
| **動畫世界觀敘事** | Hinge × the STUDIO「Dating Apocalypse」 | 中高。需要美術方向先定死 |
| **純打字動態** | @visualizevalue | 高，但數據顯示不該當開場 |

Seedance 2.0 支援最多 9 個 reference 輸入，包含 @style reference（吃圖的光線、色調、氛圍），以及用前一段生成片當 video_reference 來延續色調與調性。
[驗證] https://higgsfield.ai/blog/generating-with-seedance-2-0

[推理] 這是 Lava 每週三篇可重複的關鍵：先做一次「Lava 視覺聖經」的 style reference 圖組（3-5 張），之後每支 Reels 都掛同一組 reference，一致性不靠人工把關。

## 4. 台灣本地案例

誠實講：**台灣沒有一個 offline-first 社交品牌把 Reels 做起來的案例可以抄。**

- @thewknd.club（46.7K）是最近的定位參照，但它的 feed 以輪播為主，Reels 不是它的成長引擎。它靠的是實體活動本身的照片與號召力。
- 台灣 IG Reels 的頭部帳號（紀卜心 950K、千千進食中 849K、那對夫妻 1.04M、Howwork 六指淵 2.88M）清一色是**真人 KOL**，形態是變裝、開箱、家庭日常。整個台灣 Reels 生態沒有可對標的「無真人品牌知識帳號」。
[驗證] https://blog.adpost.com.tw/KOL_InfluencerRanking/taiwan_ig_reels

**[推理] 這反而是機會而非壞消息。** 台灣的 Reels 生態被真人 KOL 佔滿，代表「有電影感、有原生音、無真人的品牌敘事短片」在台灣中文語境幾乎是空白帶。歐美已經有 Hinge 動畫、@222place 做了，台灣沒有。

可參考的台灣製作方法論（非 Reels，但方法可移植）：
- **簡訊設計／圖文不符／志祺七七**（張志祺）：台灣懶人包始祖，核心能力是把公共議題壓縮成資訊設計。張志祺公開講過他的作法是「重複做無聊但正確的事」。
[驗證] https://www.cw.com.tw/article/5137634

## 5. 可直接偷的東西

按執行難度排序，每項標來源。

**開場（前 3 秒）**
1. **用畫面事件開場，不要用字卡開場。** 第一秒必須有一個物理動作發生：手機被放下、椅子被拉開、酒杯被推過桌面。字最早第 1.5 秒才進。｜來源：highviz.io（B-roll 9.1% vs 純字卡 5.3%）
2. **開場給一個違反預期的畫面，不是給一句違反預期的話。** ｜來源：@hinge「Dating Apocalypse」以視覺荒謬感開場
3. **原生音必開。** Seedance 生成環境音（咖啡廳雜訊、椅子摩擦、通知聲），不套熱門音軌。｜來源：highviz.io 最常見弱點為「缺少口說內容」

**結構**
4. **單支只承載一個轉折，12-15 秒。** 九張輪播抽第 3 張或第 6 張的單一知識點做一支。｜來源：highviz.io（<15s 66.9%）
5. **系列化命名，讓演算法歸類。** 例：#不聊天研究室 每支同一開場運鏡、同一字卡樣式、同一收尾。｜來源：@dailystoic 主題系列作法；@visualizevalue TRAIN 的 Restraint

**視覺約束（寫死，不再逐支決定）**
6. **一組固定的 style_reference 圖（3-5 張），每支 Seedance 生成都掛。** 光線、色溫、鏡頭焦段全部由 reference 決定，不寫在 prompt 裡。｜來源：Seedance 2.0 @style reference 機制
7. **用前一支的成品當下一支的 video_reference，做跨支調性連續。** ｜來源：Higgsfield 官方 Seedance 2.0 連續性教學
8. **字只用兩級：一句 hook（大）＋一句註記（小）。禁止第三級。** ｜來源：@visualizevalue TRAIN 的 Typography + Restraint

**人的處理**
9. **POV／手部／背影三選一，永遠不給臉。** 這不是妥協，是風格。｜來源：faceless UGC 主流格式
10. **知識點角色化。** 三種依附型態＝三個固定的非人角色，Seedance image_references 鎖定。｜來源：@thesecurerelationship 的鳥

**收尾**
11. **CTA 不放最後一格，放在第 8 秒的畫面裡（場景中的實物）。** 最後兩秒留給一個開放畫面，提高 replay。｜[推理] 依據 retensis 的 replay rate >1.1 為高於平均

## 6. 不該學的

| 做法 | 誰在做 | 為什麼不適合 Lava |
|---|---|---|
| **Kinetic typography 純字卡** | 市場上大量 faceless 教學都在推 | 數據顯示純字卡開場互動只有 5.3%，且疊字會把完播從 46.8% 拉低到 37.4%。這正是 Jesse 批評的東西換一個包裝 |
| **用戶故事／情侶見證** | @breeze.social、@thursday | Lava 用戶量不足以產出真實素材。用 AI 生成的「用戶見證」是造假，違反「不可以承諾程式或流程做不到的事」 |
| **街頭快閃／實體事件現場** | @thursday、@thewknd.club | Lava 沒有實拍能力，也沒有足夠規模的實體活動。硬做會露餡 |
| **靜態極簡字卡走量** | @womany（221K）、@海苔熊（76.3K） | 這條路在台灣的天花板約 20 萬，而且不解決 Reels 觸及問題。Lava 在 200 追蹤的階段更需要突破，不需要維穩 |
| **一次性高製作費的品牌動畫** | Hinge × the STUDIO | Lava 是一人團隊每週三篇。做得出一支不代表做得出五十支。任何不能程式化重複的方案都不該進 |
| **雞湯／勵志敘事框** | @dailystoic 等 | 品牌禁忌明列。且勵志題材是 Reels 最擁擠的紅海 |
| **AI 生成「像真人在講話」的口播** | 大量 faceless AI 帳號 | 直接命中「AI 味」禁忌。原生音要用環境音與音效，不是合成人聲旁白 |

## 7. 我方案裡最弱的一環

**我沒有實際看到任何一支競品 Reels 的播放數與畫面。**

Instagram 對登出使用者封鎖 Reels 分頁（我用瀏覽器打開 @thewknd.club/reels/ 只拿到登入牆截圖），而登入他人帳號不在我的可執行範圍。我拿到的追蹤數、bio、貼文型態是可驗證的，但**「@222place 的 Reels 到底長什麼樣、哪一支跑得好」我是靠第三方描述與縮圖推論的，不是看過的**。

具體風險：
1. 我說 @222place 可移植性最高，是基於它的定位同構與「Reels 為主體」的結構觀察，不是基於看過它的畫面語言。**這個推論可能整個錯。**
2. highviz.io 的 315 支樣本，中位數播放量只有 341。這是小帳號樣本池，跟 Lava 現況（200-260 觸及）其實吻合，但它不能外推到大帳號的行為。retensis 的 benchmark 表更弱，該文明確沒有引用任何外部研究，是業者自有數據。
3. @heavenravenofficial 我拿到兩個衝突的追蹤數（搜尋結果 231K，實際抓取 804K）。[待查]

**修正這個弱點的最低成本作法：** Jesse 自己登入 IG，打開 @222place、@breeze.social、@hinge 三個帳號的 Reels 分頁，截 9 宮格（含播放數）給我。三張截圖，五分鐘，就能把上面整段從 [推理] 升級成 [驗證]，並直接反推該做什麼開場。這件事我做不到，他做得到。

**建議的驗證設計：** 別把 Reels 當作要一次做對的東西。用兩支對照組（投影片轉檔）＋兩支導演版，比的不是讚數，是**3 秒留存率與完播率**這兩個 IG 後台看得到的數字。讚數在 200 追蹤的量級沒有統計意義，留存率有。
