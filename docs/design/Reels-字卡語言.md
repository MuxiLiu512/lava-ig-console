# Reels 字卡語言 v2（2026-08-22，源自 Jesse 提供的參考）

參考：〈愛情城市〉輪播（螢光雙色、手繪圈註）、〈微醺大飯店〉Reels（直排明體、
手寫重點字快閃、黑底開場影像浮現）、同系列紀錄片式明體字幕快剪。

## 五個手法（render_reel.py 已全部支援）

| 手法 | spec 寫法 | 用途 |
|---|---|---|
| 直排明體 | `"layout":"v"` ＋ run `"f":"ming"` | 電影感主文，台味溫度 |
| 手寫重點字 | run `"f":"hand"`（辰宇落雁體，OFL 可商用） | 溫度與人味，字級 1.4 到 2 倍 |
| 快閃輪換 | 連續多張 `"cut":true` 卡，每張 0.4 到 0.9 秒 | hook：候選詞輪換後停在答案 |
| 手繪圈註 | run `"circle":"neon_pink"` | 圈住效能陳述或答案詞 |
| 黑底開場 | `"intro_fade":{"st":3.0,"d":1.2}` | 字先講話，影像後浮現 |

## 色彩

黑底段：白明體＋螢光粉/綠重點。亮底段：深墨明體＋螢光粉重點、橘圈。
注意：螢光粉綠是跟參考學的語言，跳出了品牌色票（橘/米/酒紅/橄欖）。
樣片 v3 用此配色待 Jesse 裁決：保留螢光系或收回品牌色系。

## 節奏鐵律（不變）

字卡切換落拍點；快閃卡 0.4 秒起跳；總長 12 到 14 秒；字速低於 4.5 字/秒
（快閃候選詞例外，因為是「掃過」不是「閱讀」）；尾卡凍格 3 秒以上利循環。
