# 影片片源規則

系統用 YouTube 影片截圖當底圖時，照這份決定「先看誰、不要看誰」。
一行一個頻道關鍵字，`#` 開頭是註解。改完存檔，下一輪找圖就照新規則。

## 為什麼需要這一份〔2026-09-08〕

我們最常用的韓劇、藝人題材，片源多半有兩種：

- **原始頻道**（tvN、Netflix Korea、經紀公司官方）：畫面乾淨，
  沒有第三方台標，通常也沒有燒死的字幕。
- **新聞台二次上傳**（娛樂新聞、影劇快報這一類）：把原片剪短、
  燒上自家台標與中文字幕再上傳。

實測「毛骨悚然的戀愛 朴恩斌」搜出來的前幾支全是二次上傳，
每一格都燒著台標與雙語字幕。那種圖鋪滿在我們的貼文上，
等於把別台的浮水印印出去——我們自己的視覺閘門本來就會擋
（watermark／credit_leak 兩條 block 規則），擋得對，但那時候
已經浪費掉一輪找圖與你逐張看的時間。

**這是片源的問題，不是「哪一格」的問題**：同一支影片的每一格都髒。
所以要在選片這一步就避開，不是抽完格再逐格挑。

試過用「畫面下方橫帶的邊緣密度」自動判斷有沒有燒字幕，實測不可用：
它量到的是「下方比中段忙」，分不出「有字」與「背景本來就複雜」，
在忙碌背景上的字幕會整個漏判。所以改用這份你看得懂、也改得動的清單。

## 註記

- 比對方式是「頻道名稱或影片標題含這個字串」，不分大小寫。
- 避開清單只是降低排序，不是完全禁止：如果只有二次上傳有這個畫面，
  系統還是會拿，但會排在最後，讓你先看到乾淨的。
- 想完全禁止某個頻道，把它加到避開清單並在後面寫 `!`（例：`某某頻道 !`）。
- **這份清單需要你補。** 我只放了實測遇到的幾家（娛樂星聞、娛樂星、GTV）。
  你比我熟台灣的娛樂頻道，看到又髒又常出現的就加一行。
  加完存檔即生效，不需要等我改程式。
